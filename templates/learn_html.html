🌐 HTML курс

HTML за 2 дня

Понятный курс по созданию веб-страниц. С нуля до полноценного лендинга за два дня обучения.

Прогресс0%
📅 День 1 — Основы HTML
1
Что такое HTML и структура документа
~10 мин • Введение
▼
HTML (HyperText Markup Language) — язык разметки для создания веб-страниц. Браузер читает HTML и отображает страницу.
html
<!DOCTYPE html> <html lang="ru"> <head> <meta charset="UTF-8"> <title>Моя страница</title> </head> <body> <h1>Привет, мир!</h1> </body> </html>
head — невидимая часть с настройками. body — всё что видит пользователь.
2
Заголовки, параграфы, текст
~8 мин • Основы
▼
HTML имеет 6 уровней заголовков (h1–h6), параграфы и теги форматирования текста.
html
<h1>Главный заголовок</h1> <h2>Подзаголовок</h2> <h3>Меньший заголовок</h3> <p>Обычный параграф текста.</p> <p>Это <strong>жирный</strong> текст, а это <em>курсив</em>.</p> <br> <!-- перенос строки -->
3
Ссылки и изображения
~10 мин • Основы
▼
Тег <a> создаёт ссылки, <img> — вставляет изображения.
html
<!-- Ссылки --> <a href="https://google.com">Google</a> <a href="page.html" target="_blank"> Открыть в новой вкладке </a> <!-- Изображения --> <img src="photo.jpg" alt="Описание фото" width="300">
4
Списки (ul, ol, li)
~8 мин • Основы
▼
ul — маркированный список, ol — нумерованный. Каждый пункт — тег li.
html
<!-- Маркированный --> <ul> <li>Python</li> <li>JavaScript</li> <li>HTML</li> </ul> <!-- Нумерованный --> <ol> <li>Шаг 1</li> <li>Шаг 2</li> </ol>
5
Таблицы
~10 мин • Основы
▼
table — таблица, tr — строка, th — заголовок ячейки, td — обычная ячейка.
html
<table border="1"> <tr> <th>Имя</th> <th>Возраст</th> </tr> <tr> <td>Максим</td> <td>17</td> </tr> </table>
📅 День 2 — CSS и формы
6
Введение в CSS
~15 мин • Стили
▼
CSS (Cascading Style Sheets) — язык стилей. Подключается через тег <style> или внешний файл.
html + css
<style> body { background: #0a0a0f; color: white; font-family: Arial; } h1 { color: #a855f7; font-size: 2rem; } .highlight { background: purple; padding: 0.5rem; border-radius: 8px; } </style> <h1>Заголовок со стилем</h1> <p class="highlight">Выделенный текст</p>
7
Flexbox — современная раскладка
~15 мин • CSS
▼
Flexbox — способ расположить элементы в строку или колонку. Используется повсюду в современном вебе.
css
.container { display: flex; justify-content: center; /* по горизонтали */ align-items: center; /* по вертикали */ gap: 1rem; /* расстояние между */ flex-wrap: wrap; /* перенос */ } .item { flex: 1; /* равная ширина */ min-width: 200px; }
8
Формы и input
~12 мин • Формы
▼
Формы позволяют пользователю вводить данные. Тег <form> объединяет поля.
html
<form action="/submit" method="post"> <input type="text" placeholder="Имя"> <input type="email" placeholder="Email"> <input type="password" placeholder="Пароль"> <textarea rows="4">Сообщение</textarea> <select> <option>Python</option> <option>HTML</option> </select> <button type="submit">Отправить</button> </form>
9
div, span, семантические теги
~10 мин • Структура
▼
div — блочный контейнер, span — строчный. Семантические теги описывают смысл содержимого.
html
<header>Шапка сайта</header> <nav>Навигация</nav> <main> <section>Секция</section> <article>Статья</article> <aside>Боковая панель</aside> </main> <footer>Подвал сайта</footer>
10
Мини-проект: Лендинг
~20 мин • Практика
▼
Применяем всё изученное — создаём простую страницу-визитку.
html
<!DOCTYPE html> <html><head> <style> * { margin:0; box-sizing:border-box; } body { background:#111; color:#fff; font-family:Arial; } .hero { min-height:100vh; display:flex; flex-direction:column; align-items:center; justify-content:center; text-align:center; } h1 { font-size:3rem; color:#a855f7; } .btn { background:purple; color:#fff; padding:.8rem 2rem; border:none; border-radius:10px; cursor:pointer; margin-top:1rem; } </style></head> <body> <div class="hero"> <h1>Максим</h1> <p>Начинающий разработчик</p> <button class="btn">Связаться</button> </div> </body></html>
