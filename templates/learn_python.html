Переменные и типы данных
~10 мин • Основы
▼
Переменная — это контейнер для хранения значения. В Python не нужно объявлять тип — он определяется автоматически.
python
# Числа age = 17 height = 1.75 # Строки name = "Максим" city = 'Киев' # Булевы значения is_student = True has_job = False # Вывод print(name, "из", city)
Функция type() показывает тип переменной: type(age) вернёт <class 'int'>

Ввод и вывод данных
~8 мин • Основы
▼
print() выводит данные, input() принимает ввод от пользователя.
python
name = input("Как тебя зовут? ") print(f"Привет, {name}!") # f-строки — удобный способ вставить переменную score = 95 print(f"Твой результат: {score} баллов")
3
Условия (if/elif/else)
~12 мин • Логика
▼
Условия позволяют программе принимать решения. Важно: в Python вместо фигурных скобок используется отступ (4 пробела или Tab).
python
age = 17 if age >= 18: print("Взрослый") elif age >= 14: print("Подросток") else: print("Ребёнок")
4
Циклы for и while
~15 мин • Циклы
▼
for — перебирает элементы коллекции. while — повторяет пока условие истинно.
python
# for с range for i in range(5): print(i) # 0 1 2 3 4 # перебор списка fruits = ["яблоко", "банан", "вишня"] for fruit in fruits: print(fruit) # while count = 0 while count < 3: print(f"Счёт: {count}") count += 1
5
Списки и операции с ними
~12 мин • Структуры данных
▼
Список — упорядоченная коллекция элементов. Можно хранить разные типы данных.
python
nums = [1, 2, 3, 4, 5] nums.append(6) # добавить в конец nums.remove(1) # удалить значение print(len(nums)) # длина: 5 # срезы print(nums[0]) # первый элемент print(nums[-1]) # последний print(nums[1:3]) # срез [2, 3]
📅 День 2 — Продвинутое
6
Функции
~15 мин • Функции
▼
def — ключевое слово для создания функции. Функции позволяют переиспользовать код.
python
def greet(name, greeting="Привет"): return f"{greeting}, {name}!" print(greet("Максим")) print(greet("Аня", "Здравствуй")) # Функция с несколькими возвращаемыми значениями def min_max(lst): return min(lst), max(lst) lo, hi = min_max([3, 1, 7, 2]) print(lo, hi) # 1 7
7
Словари (dict)
~12 мин • Структуры данных
▼
Словарь хранит пары ключ: значение. Очень часто используется в реальных проектах.
python
user = { "name": "Максим", "age": 17, "city": "Киев" } print(user["name"]) # Максим user["age"] = 18 # обновить user["job"] = "разработчик" # добавить for key, val in user.items(): print(f"{key}: {val}")
8
Классы и ООП
~20 мин • ООП
▼
Классы — шаблоны для создания объектов. __init__ — конструктор, вызывается при создании объекта.
python
class Dog: def __init__(self, name, breed): self.name = name self.breed = breed def bark(self): return f"{self.name} говорит: Гав!" def info(self): return f"{self.name} ({self.breed})" dog = Dog("Рекс", "Овчарка") print(dog.bark()) print(dog.info())
9
Обработка ошибок (try/except)
~10 мин • Продвинутое
▼
try/except позволяет обработать ошибки без остановки программы.
python
try: num = int(input("Введи число: ")) print(10 / num) except ValueError: print("Это не число!") except ZeroDivisionError: print("Нельзя делить на ноль!") finally: print("Программа завершена")
10
Модули и импорт
~8 мин • Продвинутое
▼
Python имеет огромную стандартную библиотеку. import подключает модули.
python
import random import math from datetime import datetime print(random.randint(1, 100)) # случайное число print(math.sqrt(144)) # корень: 12.0 print(datetime.now()) # текущее время
